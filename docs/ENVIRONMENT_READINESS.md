# Среда разработки

Проверено и подготовлено 2026-10-10. Инструменты проекта находятся в `.tools/`, системные Rust и Java не заменены. Подключение окружения: `source scripts/env.sh`.

| Компонент | Состояние |
|---|---|
| ПК | Linux x86_64, 15 GiB RAM, RTX 4060 Laptop GPU с 8188 MiB VRAM; драйвер доступен через nvidia-smi |
| Rust | Локальный 1.90.0, rustfmt/clippy, Android arm64/x86_64 targets; host tests и arm64 JNI-сборка проходят |
| Java / Gradle | Temurin 17.0.20.1, Gradle 8.11.1 и wrapper с SHA-256 |
| Android SDK | Platform 35, build-tools 35.0.0, NDK 27.2.12479018, platform-tools 37.0.1 |
| Python | Локальный Python 3.12.15 через uv, runtime-зависимости и lock-файл; окружение `indexer/.venv/` |
| E5 | Закреплённый INT8 ONNX и tokenizer; кодирование и поиск на ПК проверены |
| Сеть | GitHub, Hugging Face, PyPI, Cargo и сервер Android SDK доступны; при больших загрузках наблюдались DNS/timeouts, используется продолжение скачивания |
| Телефон | Модель 22041216G / xaga, Android 14 / API 34, arm64-v8a; около 7,3 GiB RAM, 3,2 GiB available и 157 GiB свободно в /data на момент первого аудита |
| ADB | Телефон авторизован; повторная установка приложения и тестового APK успешна, device probe прошёл |
| Git | Репозиторий инициализирован; коммитов и удалённого origin пока нет |

APK и тестовый APK собраны и установлены. Android unit tests, lint и проверка JNI/E5 на физическом устройстве проходят. Первый запрос, включая загрузку токенизатора, занял 597 мс; максимальное отклонение вектора от ПК — 1,49×10⁻⁸. Серийный номер и персональные данные в документацию не включены.

VLM/Ollama и инференс на GPU ещё не проверены. Для реальных чатов нужны конфиг и самостоятельная локальная авторизация пользователя; Telegram-сессия не создавалась. Без этого можно продолжать тестирование на искусственных данных.

Первый полный bootstrap занимает время и несколько гигабайт диска. Повторные сборки используют локальные кеши. Проверки и команды — в [README](../README.md) и [статусе реализации](IMPLEMENTATION_STATUS.md).

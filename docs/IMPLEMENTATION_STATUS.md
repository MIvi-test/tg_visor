Устройство реализации описано в [архитектуре](ARCHITECTURE.md), команды и диагностика — в [руководстве](OPERATIONS.md), интерфейсы — в [API](API.md).

## Дополнения интерфейса

Добавлены сохраняемая тёмная/светлая тема, раскрываемый блок фильтров, локальная история последних 20 запросов с очисткой, постоянный статус модели и отдельная карточка архива с временем импорта. Для старых импортов без сохранённого времени отображается «дата неизвестна». E5-small можно скачать из приложения по HTTPS с закреплёнными revision, размерами и SHA-256; запросы и архив не отправляются. Загрузка выполняется в активном приложении, без resume и фонового сервиса; при закрытии процесса потребуется повторить загрузку.

Проверки дополнений: debug/test APK собраны, Android unit tests и lint проходят. На телефоне успешно выполнены интернет-загрузка и импорт модели, проверено сохранение темы и истории после перезапуска. Device probe повторно прошёл: query 628 мс, максимальная ошибка вектора 1,49×10⁻⁸. Прерывание сети и загрузка при нехватке места отдельно на устройстве ещё не проверялись.

## Проверки ПК

- `cargo test --workspace --locked`: 6 integration tests.
- `cargo fmt --all --check`, clippy с `-D warnings`: проходят.
- Python unittest: 4 проверки контракта, упаковки, области выбранных чатов/дат и запрета внешнего VLM endpoint.
- Rust → Android arm64: сборка JNI успешна; сегменты ELF выровнены на 16 KiB.
- `assembleDebug`, `assembleDebugAndroidTest`, `testDebugUnitTest`, `lintDebug`: проходят; lint не обнаружил ошибок. Предупреждения о закреплённых версиях библиотек и arm64-only сборке не мешают тестированию целевого устройства.
- Снимок с настоящими E5-векторами: «спящий человек» → `sleep`, «мем про усталость после работы» → `work`; фильтр отправителя `bob` оставляет `cat`/`dog`.

Тёплые короткие запросы E5 на ПК: 3,16 / 2,44 / 2,94 / 2,85 мс; пиковая RSS процесса около 499 MiB. Это небольшой CPU probe, не статистика производительности большого архива и не оценка качества retrieval. Использован один INT8-артефакт revision `614241f622f53c4eeff9890bdc4f31cfecc418b3`.

## Ограничения первого прототипа

На Xiaomi проверен системный файловый диалог: после снятия MIME-фильтра оба пакета `e5-small.zip` и `demo-v2.zip` видны в `Downloads/TGFeature-demo`. Диалог начинает выбор с «Загрузок»; содержимое выбранного пакета проверяется при импорте независимо от MIME-типа.

На телефоне модель 22041216G, Android 14 / API 34, device probe прошёл на четырёх искусственных записях: JNI, E5, первый результат семантического поиска, фильтр отправителя и отклонение закрытого handle. Первый запрос с загрузкой токенизатора — 597 мс; max absolute vector error относительно ПК — 1,49×10⁻⁸. Это единичная проверка, не p95 и не замер большого архива. Для передачи бинарных тестовых файлов используется `adb exec-in`, а не shell.

Модель и данные импортируются раздельно. APK принимает только проверенные хеши текущего E5-артефакта. Старые снимки сохраняются, автоматическая уборка и интерфейс отката отсутствуют. Обновления из папки запускаются по кнопке, HTTPS не реализован. Лексическая ветвь пока ищет токены без русской морфологии и опечаток. Векторы хранятся в RAM; масштабирование нужно измерить.

Инструменты и веса находятся в игнорируемых `.tools/` и `models/`; локальные пакеты — в `data/`. Секреты Telegram и реальные сообщения не использовались. Публикаций во внешние сервисы не было.

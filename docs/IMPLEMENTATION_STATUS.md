# Статус tgVisor v0.1.1

Дата: 2026-10-11. Это рабочий автономный прототип для Android arm64 API 26+, с подготовкой индекса на Linux-ПК. Качество поиска на мемах ещё не оценено систематически.

## Реализовано

- Python collector читает явно выбранные Telegram-чаты. Авторизация и session остаются на ПК. RPC ограничены до 2/с по умолчанию; есть FloodWait, heartbeat, прогресс и ротируемые приватные логи. Для анимированных фото выбирается статическое изображение.
- Основная разметка: Florence-2-base-ft на CPU/CUDA и EasyOCR ru/en. Веса закреплены по revision/SHA-256, удалённый custom code не выполняется. Есть кеш с профилем обработки и возобновление; старые MP4 декодируются локально через FFmpeg. Дополнительный Ollama backend использует Instruct без thinking.
- E5-small INT8 на CPU создаёт нормализованные 384-мерные векторы. Экспорт включает SQLite, FTS5, векторы, превью и манифест с хешами. Формат снимка остаётся v1 независимо от версии приложения.
- Rust выполняет точный cosine search, FTS5 и объединение RRF; фильтры учитывают чат, отправителя, даты и тему. В Android есть раскрываемые фильтры чата/отправителя/дат; фильтр темы доступен только в ядре.
- Android импортирует модель и снимок отдельно, проверяет файлы и переключает активную версию. E5 скачивается также из интерфейса по HTTPS. Есть сохраняемая тёмная/светлая тема, история 20 запросов, статус модели, время импорта, превью и источники.
- Источники открываются через `tg://resolve` / `tg://privatepost`, с HTTPS fallback. Поддерживаются ссылки тем, альбомов и комментариев; посторонние действия Telegram отклоняются.
- Папка доставки с ZIP/`latest.json` обновляется вручную по кнопке. Syncthing может использоваться как внешний транспорт.
- Название приложения — **tgVisor**, иконка — глаз с бриллиантом; есть адаптивная Android-иконка. Версия APK 0.1.1, versionCode 2.

## Проверки и измерения

На ПК с 16 ГБ RAM и RTX 4060 Laptop 8 ГБ VRAM завершена Florence/OCR-разметка 1173 выбранных изображений. После возобновления 735 новых обработаны за 217,8 с, 438 взяты из кеша. Это время оставшейся части, а не полного первого прогона. Полный каталог экспортирован в снимок и импортирован на телефон. Примерные расчёты времени приведены в [README](../README.md#сколько-времени-занимает-подготовка-базы).

Проверены 6 Rust integration tests, 41 Python unittest и 7 Android unit tests. Rust fmt/clippy, Android build/lint проходят. На Xiaomi 22041216G, Android 14 проверены JNI, E5, поиск/фильтры, импорт/скачивание модели, сохранение темы и истории. Device probe дал максимальную ошибку E5 относительно ПК 1,49×10⁻⁸; `tg://` имеет обработчик официального Telegram. Приватные сообщения не открывались автоматически для проверки ссылок.

## Ограничения

Florence описывает видимую сцену по-английски; `meaning` пустой. Интерпретация шуток, ANN, реранкер, русская морфология и исправление опечаток отсутствуют. Векторы целиком в RAM. Нет benchmark 10k/50k/100k и размеченного набора запросов для оценки ranking.

Перепроверка удалений и изменённых подписей, фоновая синхронизация, HTTPS-доставка снимков, автоматическая уборка и UI отката не реализованы. Интернет-загрузка модели работает в активном приложении без resume. Валидный снимок другой embedding_space может активироваться и отключить поиск до импорта совместимой модели.

Релизы содержат тестовый debug APK; постоянный release-ключ и CI не настроены. Интеграции exteraGram и Obtainium нет. Личные изображения, базы, session и `.env` не входят в Git и релиз. Систематические проверки lifecycle, сетевых сбоев и нехватки места ещё предстоят.

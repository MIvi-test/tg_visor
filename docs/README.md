## Границы текущей версии

Это отдельное Android-приложение, а не расширение exteraGram. Поиск выполняется локально по текстовым описаниям изображений; Telegram используется для подготовки данных на ПК и открытия найденного сообщения. Установка APK и доставка индекса — разные процессы. Интеграция Obtainium, фоновая синхронизация, ANN и реранкер пока не реализованы.

Синтетическая демонстрация подтверждает работоспособность компонентов, но не качество на реальном архиве. Оценку реальных мемов и производительности большого индекса следует проводить по критериям плана. При расхождении старого плана с текущим поведением сверяйте статус и исходный код, ссылки на который приведены в архитектуре и API.
